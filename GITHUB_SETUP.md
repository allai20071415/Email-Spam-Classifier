## Recommended Repository Name
`email-spam-classifier`

## Description
Machine Learning-based Email Spam Classifier using NLP, TF-IDF, Naive Bayes, Logistic Regression, and SVM.

## Commands

```bash
cd Email_Spam_Classifier
git init
git add .
git commit -m "Initial commit - Email Spam Classifier"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/email-spam-classifier.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username.
